# NewsOrbit privacy policy

[Read the privacy policy](https://devay2k8.github.io/newsorbit-privacy-policy/privacy.html)

[Publisher content and credits](https://devay2k8.github.io/newsorbit-privacy-policy/publisher-credits.html)

This repository contains the static privacy policy for NewsOrbit 0.1.0 alpha. GitHub Pages publishes plain HTML from the main branch. The website contains no advertising or analytics scripts and does not host news articles, publisher photographs or publisher logo assets.

The policy describes local storage, direct publisher requests, extractive summaries, disposable article caching, optional offline speech, deletion, exports and support. Source credit does not grant content-reuse rights; required permissions remain subject to publisher-specific review before public app distribution.
